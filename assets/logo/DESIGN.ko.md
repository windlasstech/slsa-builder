## 1. 개요와 콘셉트

SLSA는 공식적으로 "salsa(살사)"라고 발음한다. 로고는 이 발음을 시각적 언어유희로 옮긴 것으로, 살사
소스가 담긴 그릇과 오른쪽 위에 꽂힌 토르티야(tortilla) 칩을 그린다. 플랫 카툰 스타일의 단일 SVG이며
viewBox는 `0 0 512 512`다.

가장 중요한 설계 제약은 소형 크기에서의 가독성이다. 파비콘과 앱 아이콘처럼 16~64px까지 축소되는 사용
맥락을 전제로 하며, 모든 실루엣 결정은 이 제약에 종속된다. 작게 줄여도 "그릇 + 칩"이라는 구도가 즉시
읽혀야 한다.

## 2. 디자인 언어

### 2.1 아웃라인

따뜻한 다크 브라운 `#3d3029`, 굵기 12px, round cap과 round join을 사용한다. 이 값은 임의의 선택이
아니라 두 초안의 절충점이다. logo-1은 차가운 거의 검정(near-black, `#1A1A1A`)에 10px 아웃라인을
썼고, logo-2는 같은 브라운 계열에 더 무거운 14px을 썼다. logo-3은 그 사이의 중간점을 의도적으로
취해, 작은 크기에서 선이 뭉개지지 않으면서도 로고 전체의 따뜻한 톤을 유지한다.

### 2.2 팔레트

색상은 역할별로 명명된 12색 팔레트로 관리하되, 최종 SVG에는 리터럴 HEX로 인라인한다. 초안(logo-2,
logo-3)은 `<style>` 블록의 CSS 커스텀 프로퍼티로 팔레트를 정의했지만, 일부 래스터라이저와 파비콘
생성 파이프라인 등 비브라우저 SVG 소비자가 CSS 변수를 지원하지 않아 색이 깨질 수 있으므로,
최종안에서는 이식성을 위해 모든 `var(--*)` 참조를 실제 값으로 풀었다. 아래 이름은 코드상의 변수가
아닌 팔레트의 역할 이름이다.

| 이름               | 값        | 역할                                            |
| ------------------ | --------- | ----------------------------------------------- |
| `--outline`        | `#3d3029` | 모든 아웃라인 스트로크                          |
| `--bowl`           | `#36a6a0` | 그릇 본체 기본색                                |
| `--bowl-shadow`    | `#27847f` | 그릇 내부 면과 측면 그림자 밴드, 받침 하단 입술 |
| `--bowl-highlight` | `#82d1c9` | 그릇 왼쪽 하이라이트 호                         |
| `--salsa`          | `#d94a34` | 살사 마운드 기본색                              |
| `--salsa-dark`     | `#ad3027` | 토마토 청크                                     |
| `--salsa-light`    | `#f47a4e` | 살사 표면의 따뜻한 하이라이트 초승달            |
| `--green`          | `#3f8f4f` | 고수잎과 녹색 비트 기본색                       |
| `--green-dark`     | `#2d6f3d` | 녹색 비트의 어두운 변주                         |
| `--chip`           | `#f4c654` | 또띠야 칩 기본색                                |
| `--chip-light`     | `#ffe183` | 칩 왼쪽 가장자리 하이라이트                     |
| `--toast`          | `#b8752f` | 칩의 토스트 스폿                                |

### 2.3 음영 기법

그라디언트, SVG 필터, 래스터 이미지는 일절 사용하지 않는다. 깊이감은 오직 플랫 채우기 레이어의
겹침으로만 만든다. 구체적으로는 세 가지 수법을 쓴다.

1. 그림자 밴드: 같은 색족의 어두운 플랫 면을 본체 안쪽에 깐다.
2. 하이라이트 스트로크: 밝은 색의 라운드 스트로크를 왼쪽 면에 얹는다.
3. 저대비 동일 색족 변주: 어둡거나 밝은 같은 계열 색으로 디테일을 분리한다.
4. 인셋 원칙: 그림자 채우기는 아웃라인 스트로크의 **내측 가장자리**에 딱 붙게 깐다. 스트로크
   중심선과 같은 궤적으로 그리면 채우기가 선의 안쪽 절반을 덮어 아웃라인이 얇아지는 단차와 가장자리
   슬리버가 생긴다. 그릇 측면 그림자와 받침대 하단 그림자 모두 스트로크 폭의 절반만큼 안쪽으로
   오프셋된 호를 쓴다.

### 2.4 코드 컨벤션

- `<style>` 블록과 CSS 클래스를 쓰지 않는다. 아웃라인 속성(`stroke`, `stroke-width`,
  `stroke-linecap`, `stroke-linejoin`)은 각 외곽선 요소의 프레젠테이션 어트리뷰트로 명시한다. 초안의
  `.ink` 클래스 방식은 CSS 미지원 렌더러에서 외곽선이 통째로 사라지는 실패 모드가 있어 폐기했다.
- 루트 `<svg>`에 `role="img"`와 `aria-labelledby`를 두고 `<title id="logo-title">`로 대체 텍스트를
  제공한다.
- 주석(`<!-- Bowl -->` 등)이 요소 그룹의 경계를 구분해, 그래픽 편집기 없이 소스만 읽어도 구조를
  따라갈 수 있게 한다.

### 2.5 다크 배경 변형

`logo-dark.svg`는 어두운 배경 위에서 쓰는 변형이다. 기하와 음영, 그리고 로고 내부의 팔레트는
`logo.svg`와 동일하고, 배경과 맞닿는 아웃라인만 `#3d3029`에서 크림 `#F5E9DA`로 치환한다. 로고 내부의
색 대비는 각 색상 서로 간의 관계이므로 배경 밝기와 무관하게 유효하며, 밝은 값이 필요한 곳은 배경과의
분리를 담당하는 외곽선뿐이다. `#F5E9DA`는 웜 팔레트와 조화되는 크림 톤으로, `#0d1117`(GitHub 다크)
수준의 어두운 배경에서도 아웃라인이 소멸하지 않는다. 변형의 `<title>`은
`slsa-builder logo (dark background variant)`로 구분한다.

## 3. 요소별 디테일과 의도

### 3.1 그릇(Bowl)

형태는 받침대 발(pedestal foot)이 달린 깊은 푸티드 볼(footed bowl)의 실루엣이다. 콤포트형 서빙 볼
계열로, 주제가 살사인 만큼 그릇도 소스를 담아 내는 서빙 볼의 형태를 택했다.

받침대 발은 그릇 본체와 별도의 path로, 본체 **뒤에** 그린다. 이 기법은 logo-1에서 물려받았다. 본체와
발을 하나의 닫힌 외곽선으로 합치면 이음새에서 선이 꺾이거나 겹쳐 보이는데, 발을 뒤로 별도 레이어로
두면 접합부가 항상 매끄럽다. 음영은 발의 하단 입술 부분에만 `--bowl-shadow` 밴드로 얹는다.

그릇 측면에는 넓은 `--bowl-shadow` 그림자 밴드가 깔리고, 하이라이트는 왼쪽에 **단 하나의 호**만
둔다. 초기에는 하이라이트 스트로크가 두 개였는데, 나란히 선 두 스트로크가 소스가 흘러내린 자국(drip
marks)처럼 읽혀 하나로 통합했다.

### 3.2 칩(Chip)

크고 직선 가장자리의 삼각형이다. 소형 가독성이 최우선이다. 둥글거나 물결 모양의 가장자리는 32px
이하에서 형태가 뭉개져 삼각형으로 읽히지 않기 때문에, 날카로운 직선 실루엣을 유지한다.

칩은 수직 쪽으로 살짝 기울여, 살사 위로 드러나는 칩 면적을 넓혔다. 칩이 더 보일수록 소형 크기에서도
구도가 또렷해진다.

토스트 스폿은 4개로, 모두 불규칙한 유기적 형태의 path다. 완벽한 원은 의도적으로 피한다. 정원은
기계적으로 읽혀 손으로 굽고 구운 질감과 어울리지 않는다. 왼쪽 가장자리에는 `--chip-light` 하이라이트
면을 얇게 깐다.

### 3.3 칩 삽입 지점(핵심 디테일)

칩이 소스에 꽂히는 접합부는 이 로고에서 가장 신경 쓴 지점이다. 원칙은 하나다. 마운드의 아웃라인이
칩의 면을 가로질러 잘라서는 안 된다. 외곽선이 칩 위를 지나가면 칩이 소스 앞에 떠 있는 것처럼 읽히고
깊이감이 깨진다.

구현은 단일 마운드 path로 이루어진다. 칩 아래 구간의 실루엣이 소스 덩어리(dollop) 곡선으로 부풀어
올라 칩의 잠긴 가장자리를 감싸며, 외곽선이 끊기지 않고 한 번의 연속 곡선으로 칩을 휘감는다.
초안(logo-3)은 마운드에 U자형 홈(U-dip)을 파고 그 위에 채우기와 외곽선이 분리된 별도의 덩어리 path를
겹쳐 같은 효과를 냈지만, 오버레이 경계에서 미세한 스파이크와 외곽선 단절이 발생해 최종안에서는
덩어리 베지어를 마운드 실루엣에 직접 병합했다.

이 구성이 전달하는 내러티브는 "칩이 소스 표면을 뚫고 들어가고, 소스가 칩을 타고 올라 붙는다"는
것이다. 채워진 덩어리 대신 가는 브리지 스트로크만 놓는 안은 검토됐지만 기각됐다. 빈 선은 허공에 뜬
선으로 읽히고, 채워진 면이어야 소스로 읽힌다.

### 3.4 살사 마운드(Salsa Mound)

실루엣은 불규칙한 유기적 곡선이다. 완벽한 기하 형태(대칭 호나 정확한 타원)는 피하고, 오른쪽이 살짝
높게 솟은 언덕 모양으로 그린다.

재료 디테일은 토마토 청크 4개(`--salsa-dark`)와 녹색 비트 3개(`--green`, `--green-dark`)다. 배치
간격에는 지터를 주고 크기는 ±20~30% 범위로 흩뜨렸다. 균등한 간격의 등차적 배열도 시도했지만
기계적으로 보여 기각했다. 진짜 살사는 재료가 오히려 불규칙하게 박혀 있다.

`--salsa-light`의 하이라이트 초승달은 마운드 표면 **안쪽**에 놓는다. 이전 버전에서는 이 하이라이트가
그릇 림 위로 삐져나오거나 마운드 가장자리에 딱 붙어 가장자리 아티팩트처럼 보였다. 지금 위치는 면의
남쪽 안쪽으로 옮겨, 표면의 윤기로만 읽히게 한다.

### 3.5 고수잎 액센트(Cilantro Leaf)

마운드 꼭대기에 아웃라인이 있는 고수잎 하나를 얹는다. 위치는 칩 삽입 지점에서 왼쪽으로 약 35px
이동시켰다. 이전에는 고수잎이 돌롭, 칩 가장자리와 함께 접합부에 몰려 있어 그 지점이 답답하게 뭉쳐
보였다. 왼쪽으로 옮기면서 삽입 지점이 시각적으로 숨 쉴 공간을 갖게 됐다.

## 4. 유래와 디자인 히스토리

최종안은 logo-3를 정제한 버전이고, logo-3는 두 초안의 의도적 하이브리드다.

logo-1에서 물려받은 것:

- 받침대 발이 있는 푸티드 볼 형태
- 날카롭고 아이코닉한 직선 삼각형 칩
- 아이콘 우선의 소형 가독성 지향

logo-2에서 물려받은 것:

- 따뜻한 팔레트와 브라운 아웃라인
- 청키하고 유기적인 살사 묘사
- "소스가 칩을 타고 오른다"는 깊이 스토리텔링
- 그릇 음영 처리
- CSS 변수 기반 팔레트 구조(logo-3까지 유지. 최종안에서는 이식성을 위해 인라인 HEX로 대체)
- 접근성 메타데이터(`role="img"`, `<title>`)

logo-3에서 최종안으로 정제된 사항:

- 칩 삽입 지점의 덩어리 오버레이를 마운드 실루엣에 병합(§3.3)
- 그릇 측면 그림자와 받침대 하단 그림자를 스트로크 내측 가장자리에 맞춰 인셋(§2.3)
- CSS 커스텀 프로퍼티와 `.ink` 클래스를 리터럴 값과 어트리뷰트로 인라인(§2.2, §2.4)

logo-1.svg, logo-2.svg, logo-3.svg는 대안 초안으로 `archived/` 서브디렉터리에 그대로 보존하며
수정하지 않는다.

## 5. 제약과 비목표

- 텍스트나 문자를 넣지 않는다.
- 그라디언트, 필터, 래스터 이미지를 쓰지 않는다.
- 외부 리소스 참조가 없는 완전 자립형 단일 SVG다.
- 모든 실루엣 결정은 소형 크기 가독성에 종속된다. 디테일은 작게 줄였을 때 살아남는 것만 남긴다.
