## 1. 개요와 콘셉트

SLSA는 공식적으로 "salsa(살사)"라고 발음한다. 로고는 이 발음과 slsa-builder라는 프로젝트 이름을
시각적 언어유희로 옮긴 것으로, 멕시코에서 전통적으로 살사를 만들 때 사용하는 현무암 절구
몰카헤테(_molcajete_) 및 그와 짝을 이루는 돌 절굿공이 테홀로테(_tejolote_), 그리고 그 안에서
만들어지고 있는 살사(_salsa roja_)를 표현하였다. 플랫 카툰 스타일의 단일 SVG이며 viewBox는
`0 0 512 512`다.

가장 중요한 설계 제약은 소형 크기에서의 가독성이다. 파비콘과 앱 아이콘처럼 16–64px까지 축소되는 사용
맥락을 전제로 하며, 모든 실루엣 결정은 이 제약에 종속된다. 작게 줄여도 "돌 절구 + 뭉툭한 절굿공이 +
붉은 내용물"이라는 구도가 즉시 읽혀야 한다.

## 2. 디자인 언어

### 2.1 아웃라인

따뜻한 다크 브라운 `#3d3029`, 굵기 12px, round cap과 round join을 사용한다. 같은 값이 그릇 내부
개구부의 아웃라인에도 쓰인다. 이 두 번째 스트로크 윤곽이 절구의 벽 두께를 보이게 하는 장치다(§3.1).

### 2.2 팔레트

색상은 역할별로 명명된 팔레트로 관리하되, 최종 SVG에는 리터럴 HEX로 인라인한다. 초안은 `<style>`
블록의 CSS 커스텀 프로퍼티로 팔레트를 정의했지만, 일부 래스터라이저와 파비콘 생성 파이프라인 등
비브라우저 SVG 소비자가 CSS 변수를 지원하지 않아 색이 깨질 수 있으므로, 최종안에서는 이식성을 위해
모든 `var(--*)` 참조를 실제 값으로 풀었다. 아래 이름은 코드상의 변수가 아닌 팔레트의 역할 이름이다.

| 이름               | 값        | 역할                                      |
| ------------------ | --------- | ----------------------------------------- |
| `--outline`        | `#3d3029` | 모든 아웃라인 스트로크                    |
| `--stone`          | `#756F68` | 현무암 본체 기본색 (그릇, 다리, 절굿공이) |
| `--stone-shadow`   | `#57514B` | 돌 그림자 밴드, 후퇴 중앙 다리            |
| `--stone-interior` | `#4E4842` | 그릇 내벽                                 |
| `--pore-dark`      | `#4B4641` | 어두운 기공 핏                            |
| `--pore-light`     | `#8C847C` | 밝은 기공 핏 (표면 밝기)                  |
| `--salsa`          | `#d94a34` | 살사 기본색                               |
| `--salsa-dark`     | `#ad3027` | 토마토 청크, 갈린 입자                    |
| `--salsa-light`    | `#f47a4e` | 살사 웜 액센트                            |
| `--green`          | `#3f8f4f` | 고수잎과 녹색 비트                        |
| `--green-dark`     | `#2d6f3d` | 녹색 비트의 어두운 변주                   |
| `--cream`          | `#F5E9DA` | 양파/마늘 조각                            |

### 2.3 음영 기법

그라디언트, SVG 필터, 래스터 이미지는 일절 사용하지 않는다. 깊이감은 오직 플랫 채우기 레이어의
겹침으로만 만든다. 구체적으로 다음의 네 가지 기법을 쓴다.

1. 그림자 밴드: 같은 색족의 어두운 플랫 면을 본체 안쪽에 깐다.
2. 저대비 동일 색족 변주: 어둡거나 밝은 같은 계열 색으로 디테일을 분리한다.
3. 인셋 원칙: 그림자 채우기는 아웃라인 스트로크의 **내측 가장자리**에 딱 붙게 깐다. 스트로크
   중심선과 같은 궤적으로 그리면 채우기가 선의 안쪽 절반을 덮어 아웃라인이 얇아지는 단차와 가장자리
   슬리버가 생긴다. 모든 그림자 호는 스트로크 폭의 절반만큼 안쪽으로 오프셋된다.
4. 광택이 아닌 핏으로 질감 표현: 거친 다공질 돌에는 스페큘러 하이라이트가 없다. 그릇 표면의 밝기
   변화는 흩뿌린 밝은 기공 핏으로만 만들며, 돌 위에 매끄러운 하이라이트 호를 그리지 않는다(§3.1).

### 2.4 코드 컨벤션

- `<style>` 블록과 CSS 클래스를 쓰지 않는다. 아웃라인 속성(`stroke`, `stroke-width`,
  `stroke-linecap`, `stroke-linejoin`)은 각 외곽선 요소의 프레젠테이션 어트리뷰트로 명시해, 어떤
  소비자에서도 동일하게 렌더링되게 한다.
- 루트 `<svg>`에 `role="img"`와 `aria-labelledby`를 두고 `<title id="logo-title">`로 대체 텍스트를
  제공한다.
- 주석(`<!-- Bowl -->` 등)이 요소 그룹의 경계를 구분해, 그래픽 편집기 없이 소스만 읽어도 구조를
  따라갈 수 있게 한다.
- 단일 래퍼 `<g transform="...">`가 광학적 정합을 담당한다. 채택안은 구도 전체를 픽셀 계측한
  아트워크 중심 기준 1.12배 확대해 viewBox 사면 마진이 균형을 이루게 했다.

### 2.5 다크 테마용 변형

`logo-dark.svg`는 어두운 배경 위에서 쓰는 변형이다. 기하와 음영, 그리고 로고 내부의 팔레트는
`logo.svg`와 동일하고, 배경과 맞닿는 아웃라인만 `#3d3029`에서 크림 `#F5E9DA`로 치환한다. 로고 내부의
색 대비는 각 색상 서로 간의 관계이므로 배경 밝기와 무관하게 유효하며, 밝은 값이 필요한 곳은 배경과의
분리를 담당하는 외곽선뿐이다. `#F5E9DA`는 웜 팔레트와 조화되는 크림 톤으로, `#0d1117`(GitHub 다크)
수준의 어두운 배경에서도 아웃라인이 소멸하지 않는다. 변형의 `<title>`은
`slsa-builder logo (dark background variant)`로 구분한다.

## 3. 요소별 디테일과 의도

### 3.1 몰카헤테(_molcajete_)

그릇은 일반 볼이 아니라 전통적인 몰카헤테의 형태를 따른다.

- **넓고 중간 깊이의 절구.** 몰카헤테는 기본적으로 절구이며 서빙 식기를 겸하기도 한다. 입구가
  넓으면서도 어느 정도 깊이가 있다. 얕은 서빙 접시도, 유럽식 약재용처럼 좁고 깊은 형태도 아니다.
- **짧은 다리 3개(삼각 지지).** 좌·우 다리는 본체색, 중앙 다리는 그림자색에 약간 짧게 그려 뒤로
  물러나 보이게 한다. 다리는 본체 뒤에 그려 접합부가 매끄럽게 유지되게 한다.
- **두터운 벽.** 림은 보이는 밴드로 읽혀야 한다. 외측 실루엣과, 자체 아웃라인을 가진 더 작은 내부
  개구부의 조합이다. 본체 상단과 내부를 하나의 타원으로 공유하면 벽 두께가 수학적으로 0이 되므로,
  내부 개구부는 반드시 별도의 더 작은 스트로크 타원이어야 한다.
- **다공질 질감.** 본체와 다리에 어두운/밝은 기공 핏을 흩뿌린다. 유기적 블롭 패스이며 완벽한 원은
  피한다.
- **무광택.** 거친 다공질 표면에는 스페큘러(specular) 호가 생기지 않는다. 유약 세라믹에 어울리던
  매끄러운 하이라이트 호는 이 이유로 제거됐다.

### 3.2 테홀로테(_tejolote_)

절굿공이는 실제 도구의 비례와 형태를 따른다.

- **뭉툭한 절두원뿔.** 실물 테홀로테는 일반적으로 길이 약 10–13cm, 연마면 지름 6–7.5cm, 손잡이 지름
  4–5cm 정도 비율의 묵직한 돌 토막이다. 길고 얇은 막대 형태의 서양식 절굿공이가 아니다. 길이 대 폭
  비율은 **1.3–2.0:1** 범위여야 하며, 이는 눈대중이 아니라 렌더된 실루엣의 픽셀 계측(PCA 범위)으로
  객관 검증한다. 채택안의 테홀로테 계측값은 1.63:1이다.
- **뭉툭한 반구형 끝.** 하단은 닳아 둥글어진 손가락 끝 같은 bulb다. 수학적으로 깔끔하게 잘린 평면도
  아니고, 긴 막대에 공을 붙인 형태도 아니다.
- **뭉툭한 돔형 손잡이 끝.** 상단(손에 쥐는 쪽)은 3차 베지어 돔으로, 양 끝점의 접선이 옆면 직선을
  그대로 연속한다. 캡과 옆면이 만나는 지점에 각진 모서리가 없다.
- **절반 정도가 그릇 밖**에 보이며 우측 상단에서 사선으로 기운다(채택안 ≈ 35°). 테홀로테는 손바닥
  전체로 움켜쥐고 내벽을 따라 비스듬히 굴려 짓비비는 도구이므로, 위아래로 찍어 누르는 수직 자세는
  피한다.

### 3.3 절굿공이-소스 접합부(핵심 디테일)

원칙은 하나다. 소스 아웃라인이 절굿공이의 면을 예각으로 가로질러서는 안 된다. 두 다크 아웃라인의
예각 교차는 웨지/슬리버 아티팩트를 만들고, 잠긴 끝을 직선 윤곽이 가로지르면 절굿공이가 소스에 잠긴
게 아니라 뒤에 꽂힌 것처럼 읽힌다.

구현은 단일 병합 소스 윤곽이다. 윤곽이 절굿공이 좌측면을 거의 평행하게 타고 올라가 면 위를 넘은 뒤
우측으로 내려오며, 소스 채우기가 잠긴 부분을 덮는다. 별도 오버레이나 "스플래시" 패스도 시도하였지만
경계에서 예각 스트로크 교차(훅, 노치)를 다시 만들기 때문에 기각하였다.

### 3.4 살사 로하(_salsa roja_)

- **소스 수면을 림 아래로** 낮춰, 절구의 어두운 내측 후면 벽이 소스 위로 노출되게 한다. "절구"와
  "만드는 중"을 동시에 전달하는 장치다.
- 절굿공이 헤드 바로 아래 **갈린 입자 클러스터**를 위치시켜, 실시간으로 몰카헤테와 테홀로테에 의해
  짓이겨지고 있는 모습을 연출한다.
- **반쯤 으깬 토마토** 하나와 통재료(다크 레드 토마토 청크, 녹색 비트, 크림색 양파/마늘 조각
  1–2개)를 지터를 줘 흩뿌린다. 균등 배열은 기계적으로 읽힌다. 진짜 살사는 재료가 오히려 불규칙하게
  박혀 있다.

### 3.5 후보 비교와 최종 결합

logo-6과 logo-7은 동일 브리프의 독립 해석이었다(§1–§3.4는 양쪽 모두에 적용됨). 채택된
`logo.svg`(시안 명 logo-8)는 검증된 양쪽의 장점을 결합한다.

| 항목               | logo-6                    | logo-7                   | 채택안                                               |
| ------------------ | ------------------------- | ------------------------ | ---------------------------------------------------- |
| 절굿공이 각도      | ~45°                      | ~35°, 더 우측 배치       | logo-7 (로컬 좌표 + transform)                       |
| 볼 곡률            | logo-4 계승의 깊은 타원   | 더 좌우로 넓은 곡률      | logo-7                                               |
| 후면 림 밴드       | 있음                      | 없음 (전면 립 처짐)      | 있음 — 상단 호 인상 (~16px)                          |
| 측면 그림자        | 분할 초승달               | 단일 연속 스윕           | 분할 초승달, 하단 호를 아웃라인 내측 가장자리에 밀착 |
| 기공               | 13개, 다리 포함           | 4개                      | logo-6 밀도, 재배치                                  |
| 소스 윤곽          | 병합 랩                   | 단일 병합 베이스+랩 패스 | logo-7 패스 그대로                                   |
| 소스 양            | 적어 보임                 | 넉넉함                   | logo-7                                               |
| 재료 디테일        | 입자, 으깬 토마토, 가니시 | 절제, 스트로크 비트      | logo-6 세트, 재배치                                  |
| 계측 절굿공이 비율 | 1.46:1                    | 1.63:1                   | 1.63:1                                               |

결합 이후 리뷰에서 추가 반영한 세부 수정:

- 초승달 섀도우의 하단 호를 볼 아웃라인 내측 가장자리에 밀착, 밝은 틈 제거(§2.3 인셋 원칙).
- 모든 소형 재료를 소스 윤곽에서 ≥8px 안쪽에 배치, 내벽에 걸치는 (원근상 불가능한) 배치 제거.
- 갈린 입자와 반쯤 으깬 토마토를 이 테홀로테의 그라인딩 지점으로 이동, 절굿공이 이동 후에도 logo-6의
  좌표를 유지하고 있던 문제 해소.
- 손잡이 끝을 접선 연속 돔으로 둥글게 처리(§3.2).
- 픽셀 계측 경계를 기준으로 구도를 1.12배 확대·재중앙 정렬.

## 4. 유래와 디자인 히스토리

- **logo-1, logo-2, logo-3**: 서빙 컨셉(살사 볼에 토르티야 칩) 초기 시안. 아카이브됨.
- **logo-4, logo-4-dark** (원래 `logo.svg` / `logo-dark.svg`): 최초 채택된 서빙 디자인. 틸 받침대
  볼(콤포트형)에 칩이 찍힌 구도와 최초의 다크 변형. 메이킹 컨셉 채택과 함께 아카이브됐으며, 다크
  변형 컨벤션(크림 아웃라인 치환, 채우기 유지)은 새 변형에 계승된다.
- **logo-5**: 서빙 컨셉을 현무암 몰카헤테로 재해석. 스톤 팔레트, 삼각 다리, 기공, 무광택 규칙을
  도입. 아카이브됨.
- **logo-6**: 메이킹 컨셉. 칩을 테홀로테로 치환하고 소스 수면을 낮춰 내벽을 노출. 렌더 실루엣의 픽셀
  계측(PCA 범위)을 통한 비례 수치 측정을 처음 도입함. 아카이브됨.
- **logo-7**: logo-6 브리프의 두 번째 독립 해석. logo-3이 logo-1과 logo-2의 장점을 모아 나온 것처럼,

## 5. 제약과 비목표

- 텍스트나 문자를 넣지 않는다.
- 그라디언트, 필터, 래스터 이미지를 쓰지 않는다.
- 외부 리소스 참조가 없는 완전 자립형 단일 SVG다.
- 모든 실루엣 결정은 소형 크기 가독성에 종속된다.
- 돌 표면에 스페큘러/광택 호를 그리지 않는다.
- 길고 얇은 막대형 절굿공이 실루엣 금지. 테홀로테 비례는 1.3–2.0:1 범위에서 객관 계측 가능해야 한다.
- 평면으로 깔끔하게 잘린 절굿공이 하단 금지.
- 절구의 벽 두께는 반드시 명시적으로 표현한다(외측 실루엣 + 더 작은 스트로크 내부 개구부).
- 다크 변형은 아웃라인 색만 바꾼다. 기하와 채우기는 라이트 파일과 동일하게 유지한다.
